### Інтелектуальна система управління особистими фінансами з прогнозуванням витрат
Система управління особистими фінансами з функціями аналізу даних, візуалізації та прогнозування витрат користувача.

## Загальна інформація
Тип проєкту: Desktop application
Мова програмування: Python 3.12
Бібліотеки: CustomTkinter, Matplotlib, Pandas, NumPy, Scikit-learn

---

## Опис функціоналу
- Створення та керування профілями користувачів
- Додавання доходів та витрат
- Категоризація фінансових операцій
- Побудова графіків і діаграм
- Аналіз фінансових даних
- Прогнозування майбутніх витрат
- Збереження даних у JSON-файл
- Експорт фінансових даних у CSV

## Як запустити проєкт "з нуля"
### 1. Встановлення Python
Необхідно встановити:
- Python 3.12
- pip


Перевірка версії:
```bash
 python --version

```
### 2. Клонування репозиторію
```bash
git clone https://github.com/galaburdal/Duplom.git
cd Duplom
```
### 3. Встановлення залежностей
```bash
pip install -r requirements.txt
```
### 4. Запуск програми
```bash
python main.py
```

## Інструкція для користувача
### Робота з профілями

Користувач може:
- створити новий профіль;
- обрати існуючий профіль зі списку.

### Додавання транзакцій

Для додавання транзакції необхідно:
- обрати тип операції;
- вказати суму;
- ввести категорію;
- обрати дату операції.

### Робота з транзакціями

Система дозволяє:
- переглядати список транзакцій;
- редагувати записи;
- видаляти фінансові операції.

### Аналітика

У модулі аналітики користувач може:
- переглядати діаграми доходів і витрат;
- аналізувати структуру бюджету;
- переглядати динаміку витрат по місяцях.

### Прогнозування

Модуль прогнозування дозволяє:
- обирати модель прогнозування;
- формувати прогноз витрат;
- аналізувати результати прогнозування.

### Експорт даних

Фінансові дані можуть бути експортовані у формат CSV.

##  Проблеми і рішення
| Проблема                  | Рішення                                    |
|---------------------------|--------------------------------------------|
| Програма не запускається  | Перевірити встановлення Python             |
| Помилка імпорту бібліотек | Виконати `pip install -r requirements.txt` |
| Не відображаються графіки | Перевірити встановлення Matplotlib         |
| Не зберігаються дані      | Перевірити наявність файлу `data.json`     |
